# m2 — Web App by Aajimin (AJ-8A)

A web application and messaging-interface project built by **Aajimin**, also known as **AJ-8A**.

**Creator:** https://github.com/AJ-8A  
**Related project:** [AJChat](https://github.com/aj-8a/AJChat)

## Current stage

The repository contains the responsive messenger UI, chat list, message composer, filters, theme toggle, typing animation, and mobile navigation.

## Next backend layer

The planned realtime stack is Cloudflare Workers + Durable Objects + D1, with object storage for media. This first commit intentionally keeps the frontend demo self-contained.
